# 러닝 훈련 플래너

현재 기록과 목표 대회를 입력하면 대회 날까지의 주간 훈련표를 만들어 주는 개인용 웹 도구입니다.

- VDOT(Daniels–Gilbert 공식) 기반 훈련 페이스 계산 (이지 / 마라톤 / 템포 / 인터벌 / 반복)
- 기초 → 강화 → 절정 → 테이퍼 → 대회 주간으로 이어지는 로드맵
- 훈련 후 느낌(쉬움/적당/힘듦/못함)을 기록하면 다음 주 강도 자동 조절
- 로그인·서버 없음. 데이터는 브라우저(localStorage)에만 저장

`index.html` 한 파일로 동작하며 GitHub Pages로 배포합니다.

일반적인 훈련 가이드이며 의학적 조언이 아닙니다.
